# NodeMG Studio — Social Analytics Dashboard

आपकी Google Sheet (YouTube + Instagram + Facebook का डेली डेटा) को YouTube Studio जैसे डैशबोर्ड में बदलने वाला प्रोजेक्ट। सिर्फ़ HTML, CSS, JavaScript और Google Apps Script — कोई build step या सर्वर नहीं।

## क्या-क्या मिलता है

| सेक्शन | क्या दिखता है |
|---|---|
| **डैशबोर्ड** | कुल Views, प्लेटफ़ॉर्म-वार Views, Engagement, पिछले दिन से तुलना, ट्रेंड चार्ट, टॉप वीडियो, ऑडियंस क्वालिटी, अगली स्क्रिप्ट के एक्शन |
| **कंटेंट** | सारे वीडियो की टेबल — सर्च, फ़िल्टर, सॉर्ट; क्लिक करने पर पूरी जानकारी |
| **YouTube / Instagram / Facebook** | हर प्लेटफ़ॉर्म के अलग मेट्रिक्स (Stayed, AVD, Non-subs, Replay, Non-followers, Saves, Shares …) |
| **कमेंट्स** | तीनों प्लेटफ़ॉर्म के कमेंट्स और हर 1000 Views पर कमेंट दर |
| **इनसाइट्स और एक्शन** | शीट के "Fix for next video" वाले हिस्से टू-डू बनते हैं (टिक किया हुआ ब्राउज़र में सेव रहता है) + डेटा से अपने-आप निकले संकेत |
| **स्क्रिप्ट पाइपलाइन** | "Pending" स्क्रिप्ट (डॉक लिंक के साथ) और पब्लिश हो चुके वीडियो |

**अलग-अलग दिन देखना:** स्क्रीन के ऊपर *डे-स्ट्रिप* में हर दिन का एक बटन है (नीचे छोटा बार उस दिन के Views बताता है)। क्लिक करके उस दिन का पूरा डैशबोर्ड देखिए। साथ में **आख़िरी दिन / 7 दिन / 28 दिन / सब** और ऊपर कैलेंडर बटन से **एक दिन या कोई भी रेंज** चुन सकते हैं। हिन्दी/English और डार्क/लाइट मोड भी है।

## फ़ोल्डर

```
index.html          डैशबोर्ड का पेज
profile.jpg         ← आप डालेंगे (आपकी प्रोफ़ाइल फ़ोटो)
youtube.jpg         ← आप डालेंगे (YouTube लोगो)
instagram.jpg       ← आप डालेंगे (Instagram लोगो)
facebook.jpg        ← आप डालेंगे (Facebook लोगो)
css/style.css       डिज़ाइन
js/config.js        नाम, भाषा, इमेज की सेटिंग
js/vault.js         पासवर्ड से लॉक की हुई निजी सेटिंग (Apps Script URL आदि)
js/gate.js          पासवर्ड वाली लॉक स्क्रीन
tools/vault-tool.html  vault.js बनाने/बदलने का टूल (ब्राउज़र में खोलिए)
tools/make-vault.js    वही काम Node से
js/parser.js        शीट के टेक्स्ट को आँकड़ों में बदलता है
js/app.js           डैशबोर्ड का सारा लॉजिक
js/i18n.js          हिन्दी/English टेक्स्ट
apps-script/Code.gs Google Sheet से डेटा देने वाली स्क्रिप्ट
```

इमेज न हों तो भी डैशबोर्ड चलता है — तब फ़ोटो की जगह अक्षर वाला आइकन दिखता है।

## सेटअप (10 मिनट)

### 1. Google Sheet को डैशबोर्ड से जोड़ना
1. अपनी शीट खोलिए → **Extensions → Apps Script**
2. `apps-script/Code.gs` का पूरा कोड वहाँ paste कीजिए। `SHEET_NAME` में अपनी tab का नाम लिखिए (जैसे `Sheet1`)।
3. **Deploy → New deployment → Web app** चुनिए
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
4. मिला हुआ URL (`https://script.google.com/macros/s/…/exec`) कॉपी कीजिए।
5. `tools/vault-tool.html` को ब्राउज़र में खोलिए → वही पासवर्ड, Data source = `appsscript` और अपना Apps Script URL भरिए → **vault.js बनाइए**। डाउनलोड हुई फ़ाइल से `js/vault.js` बदल दीजिए।
6. पेज खोलिए, पासवर्ड डालिए। साइडबार के नीचे **"Google Sheet से लाइव"** दिखे तो जुड़ गया।

> Apps Script का कोड बदलने पर: Deploy → Manage deployments → ✏️ → **New version** → Deploy।

**बिना Apps Script के विकल्प:** Sheet में *File → Share → Publish to web → CSV* चुनकर लिंक लीजिए और vault-tool में Data source = `csv` चुनकर वह लिंक डालिए। (इसमें शीट का कोई भी हिस्सा सबको दिख सकता है और अपडेट आने में कुछ मिनट लग सकते हैं।)

### 2. चलाना / ऑनलाइन डालना
- **अपने कंप्यूटर पर:** फ़ोल्डर में `python3 -m http.server 8000` चलाकर `http://localhost:8000` खोलिए (या सीधे `index.html` खोलिए)।
- **GitHub Pages:** रिपॉजिटरी push कीजिए → *Settings → Pages → Deploy from a branch → main / root*। Netlify या Cloudflare Pages पर भी यही फ़ोल्डर चलता है।

रोज़ शीट में नई row जोड़िए — पेज दोबारा खोलने या ऊपर के 🔄 बटन पर डेटा नया आ जाता है। हर कुछ मिनट में अपने-आप चाहिए तो `autoRefreshMinutes: 10` कीजिए।

## शीट का फ़ॉर्मेट (डैशबोर्ड क्या समझता है)

कॉलम उनके **नाम** से पहचाने जाते हैं (नाम वही रखिए जो अभी हैं; कॉलम आगे-पीछे हों तो भी चलेगा)। पहली row हेडर होनी चाहिए।

| कॉलम | इस तरह लिखिए |
|---|---|
| Date | `2026-10-19` (या `19/10/2026`) |
| Video / Script Title | `Script 03: नाम (टैग)` या `नाम (Script 02 - टैग)` — `Script NN` और आख़िरी `( )` अपने-आप बैज/टैग बन जाते हैं |
| Video / Doc Link | YouTube लिंक → थंबनेल + "वीडियो खोलें"; Google Doc लिंक → "स्क्रिप्ट खोलें" |
| YouTube Views / Engaged Views / Likes | सिर्फ़ नंबर |
| YouTube Stayed to Watch % & AVD | `50.7% Stayed • 0:17 / 0:44 AVD (97.5% Non-Subs • 17.3% TV)` |
| Instagram Views | नंबर |
| Instagram Unique Viewers & Replay | `135 Viewers (8.88x Replay • 91.9% Non-Followers)` |
| Instagram Reactions | `7 Likes / 0 Saves / 0 Shares` |
| Facebook Views / Reactions | `1037` / `6 Reactions` |
| Total Views | नंबर (खाली हो तो तीनों का जोड़ लिया जाता है) |
| Top Comments | `0 Comments across YT / IG / FB` या असली कमेंट: `YT: बढ़िया ट्रिक \| IG: 🔥 \| FB: शुक्रिया` (हर कमेंट नई लाइन में भी चलेगा) |
| Key Insights & Action for Next Script | `…विश्लेषण… Fix for next video: पहला; दूसरा; तीसरा` — `;` से बँटा हर हिस्सा एक टू-डू बनता है |

**स्क्रिप्ट जो अभी पब्लिश नहीं हुई:** आँकड़ों के कॉलम में `Pending` लिखिए → वह "पब्लिश के लिए तैयार" में जाएगी और आँकड़ों में नहीं गिनी जाएगी। वीडियो डालने के बाद उसी row में असली नंबर भर दीजिए।

## पासवर्ड लॉक — यह कैसे काम करता है

पेज खुलते ही सिर्फ़ प्रोफ़ाइल, नाम और पासवर्ड बॉक्स दिखता है; सही पासवर्ड पर ही डैशबोर्ड खुलता है। ऊपर 🔒 बटन से दोबारा लॉक कर सकते हैं (टैब बंद होने पर भी लॉक हो जाता है)।

- पासवर्ड **कोड में कहीं नहीं** है — न सादे रूप में, न hash के रूप में। View-source या Inspect में कुछ नहीं मिलता।
- आपकी निजी सेटिंग (Apps Script URL, key, डेमो डेटा) `js/vault.js` में **AES-256-GCM** से एन्क्रिप्ट है। ताला खोलने की चाबी पासवर्ड से PBKDF2 (3,10,000 चक्कर) द्वारा बनती है, इसलिए ग़लत पासवर्ड से कुछ पढ़ा नहीं जा सकता।
- 3 ग़लत कोशिश के बाद कुछ सेकंड का इंतज़ार लगता है।
- **पासवर्ड बदलना:** vault-tool में नया पासवर्ड डालकर नई `vault.js` बनाइए और बदल दीजिए।
- **सीमा (ज़रूरी):** यह स्टैटिक वेबसाइट है, सर्वर नहीं। इसलिए कोई इंसान `vault.js` डाउनलोड करके अपने कंप्यूटर पर पासवर्ड अंदाज़े (brute-force) लगा सकता है। लंबा और अनोखा पासवर्ड इसे बहुत मुश्किल बनाता है, पर 100% असंभव नहीं। जो पासवर्ड कहीं और इस्तेमाल करते हैं वह यहाँ न रखें।
- पासवर्ड सही डालने के बाद Apps Script URL ब्राउज़र के Network टैब में दिखता है (यह उसी इंसान को दिखता है जिसे पासवर्ड पता है)। जिस शीट में बहुत निजी जानकारी हो उसे इस तरीके से न जोड़ें।
- पासवर्ड आपने यहाँ चैट में लिखा है; इसलिए अगर यह चैट किसी और को दिखती है तो पासवर्ड बदल लीजिए।

## ध्यान देने की बातें

- **Apps Script की पहुँच:** Apps Script "Anyone" पर है, इसलिए URL जिसके पास हो वह आपकी शीट का डेटा पढ़ सकता है। `accessKey` (vault में रखी जाती है) अनजान लोगों को रोकने में मदद करता है, पर URL और key जिसके पास हों वह डेटा पढ़ सकता है। डेटा पूरी तरह निजी रखना हो तो डैशबोर्ड सिर्फ़ अपने कंप्यूटर पर चलाइए, या पासवर्ड/लॉगिन वाली होस्टिंग (जैसे Cloudflare Access) इस्तेमाल कीजिए। शीट में निजी चीज़ें (फ़ोन, ईमेल) न रखें।
- **इंटरनेट चाहिए:** फ़ॉन्ट और चार्ट लाइब्रेरी (Chart.js) CDN से आते हैं।
- **इमेज थंबनेल:** YouTube लिंक होने पर थंबनेल `i.ytimg.com` से आता है।
- **टिक किए हुए एक्शन** उसी ब्राउज़र में सेव रहते हैं (शीट में नहीं लिखे जाते)।
- अगर शीट न मिले तो डैशबोर्ड आख़िरी सेव की हुई कॉपी दिखाता है और ऊपर चेतावनी देता है।
